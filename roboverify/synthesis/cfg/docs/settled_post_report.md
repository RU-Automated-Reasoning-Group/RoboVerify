- **Model requests:** none. Every result below was computed by restoring saved simulator snapshots.

Every frozen CaP version uses the default, so fresh Unstack and Reverse scenes are settled; 0 reproduces the earlier unsettled runs. See [`cfg/AGENTS.md`](../AGENTS.md#settling).
